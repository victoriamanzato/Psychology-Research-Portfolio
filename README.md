# Psychology-Research-Portfolio
My name is Victoria Manzato and I'm a senior studying Psychology (Behavioral and Cognitive Neuroscience track) and Statistics. I'm passionate about using psychology and research to help people, specifically those with chronic disease/pain, mood disorders, and the interaction between them. 

Throughout my time at UF, I have worked at three different labs, learning and applying statistical analysis methods within lab assignments as well as in personal projects. 


## Programming & Software

- **R:** dplyr, readr, ggplot2, ppcor
- **Python:** Coursework in programming and computational mathematics (COP 3502C, MAD 2502)
- **Neuroimaging:** AFNI (fMRI preprocessing)
- **Data Pipelines:** Automated R scripts that turn PsychoPy task output into fMRI event-timing files for four tasks, with quality-control checks
- **Reproducibility:** R Markdown

## Statistical Methods

- **Nonparametric Testing:** Spearman and partial Spearman correlation, Mann-Whitney U / Wilcoxon rank-sum, Fisher's exact test
- **Effect Sizes:** Rank-biserial correlation
- **Regression:** Multiple linear regression with interaction terms and residual diagnostics
- **Multiple Comparisons:** Benjamini-Hochberg false discovery rate correction
- **Signal Detection:** d′ with log-linear correction
- **Visualization:** Correlation heatmaps, effect-size forest plots, scatterplots with fitted regression lines (ggplot2)
