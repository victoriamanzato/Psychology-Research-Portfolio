# Psychology-Research-Portfolio
My name is Victoria Manzato and I'm a senior studying Psychology (Behavioral and Cognitive Neuroscience track) and Statistics. I'm passionate about using psychology and research to help people, specifically those with chronic disease, substance abuse, mood disorders, and the interaction between all three. 

Throughout my time at UF, I have worked at three different labs, learning and applying statistical analysis methods within lab assignments as well as in personal projects. 


Key Skills & Quantitative Tools

### Programming & Software
* Statistical Languages:** R (e.g., `tidyverse`, `lme4`, `ggplot2`), Python (e.g., `pandas`, `numpy`, `statsmodels`)
* Experimental / Behavioral Task Design:** PsychoPy, Qualtrics (JS / Advanced Piping)
* GUI Software:** SPSS, AFNI

### Statistical Methods & Modeling
* Parametric & Non-Parametric Testing:** ANOVA / ANCOVA, Repeated Measures, Chi-Square, Non-parametric equivalents
* Regression & Multivariate Analysis:** Multiple Linear Regression, Logistic Regression, Moderation & Mediation Analysis
* Advanced Methods:** Linear Mixed-Effects Models (LMM/HLM), Structural Equation Modeling (SEM), Confirmatory Factor Analysis (CFA)
* Data Processing:** Power Analysis (`G*Power`, `pwr`), Missing Data Handling (Multiple Imputation via `mice`), Outlier Detection & Transformation

### Open Science & Workflow
* Reproducibility:** Git/GitHub, R Markdown
* Open Science Platforms:** OSF (Open Science Framework), Pre-registration protocols, Data Anonymization pipelines
